Класс TodoApp

Главный класс приложения для управления задачами.

Методы

__init__(self, root)
Конструктор, инициализирует приложение, загружает задачи из JSON

add_task(self)
Добавляет новую задачу из полей ввода

complete_task(self)
Отмечает выбранную задачу как выполненную

edit_task(self)
Открывает окно редактирования выбранной задачи

delete_task(self)
Удаляет выбранную задачу

show_stats(self)
Показывает статистику всего задач, выполнено, просрочено, по приоритетам

refresh_task_list(self)
Обновляет таблицу задач с учетом текущего фильтра

sort_by_column(self, col)
Сортирует таблицу по указанной колонке

save_tasks(self)
Сохраняет задачи в файл todo_list.json

load_tasks(self)
Загружает задачи из файла todo_list.json

setup_styles(self)
Настраивает цвета и стили интерфейса

create_widgets(self)
Создает все элементы интерфейса

on_closing(self)
Обрабатывает закрытие окна, сохраняет данные

Структура задачи словарь

id уникальный номер
title название задачи
priority приоритет high medium low
deadline срок выполнения ГГГГ ММ ДД
created дата создания
completed статус выполнения True False
completed_date дата выполнения

Фильтры

all все задачи
active только активные
completed только выполненные
overdue только просроченные

Файл данных

todo_list.json хранит все задачи в формате JSON
